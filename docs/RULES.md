# Правила внесения изменений (для защиты, выучи наизусть)

1. **Цикл:** задача → ветка `feature/<что>` → 2–3 осмысленных коммита → Pull Request → проверка → merge в `main`.
2. **Обязательные проверки перед пушем:** `python check.py` (или `make test` / `make verify`). Красное — не пушим.
3. **Запрещено:** коммитить `.env`, `*.db`, `__pycache__`; удалять/ослаблять проверки; пушить напрямую в `main`; класть пароли в код.
4. **Приёмка:** PR смотрит второй студент; `check.py` зелёный; показано в браузере `/` и `/health`; после merge — тег версии (`git tag v0.1.0`).
5. **Критические файлы** (меняем только через PR вдвоём): `app.py`, `schema.sql`, `check.py`, `Makefile`.
