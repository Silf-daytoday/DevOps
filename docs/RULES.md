# Правила внесения изменений

1. **Цикл:** задача → ветка `feature/<что>` → 2–3 коммита → Pull Request → проверки → merge в `main`.
2. **Обязательные проверки:** перед пушем выполнить `python check.py` (или `make verify`). При ошибках пуш не выполняется.
3. **Запрещено:** коммитить `.env`, `*.db`, `__pycache__`; удалять или ослаблять проверки; пушить напрямую в `main`; хранить секреты в коде.
4. **Приёмка:** ревью второго участника, статус `check.py` — успешно, демонстрация в браузере `/` и `/health`; после merge — тег версии (`git tag v0.1.0`).
5. **Критические файлы** (изменения только через PR): `app.py`, `schema.sql`, `check.py`, `Makefile`.
