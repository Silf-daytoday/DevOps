# Описание для PR в develop

ЛР3, вариант 8. Добавлены комментарии к оценкам, время новых записей,
версионированные миграции и единый локальный проверочный контур.

- Pytest unit/API/web-тесты и изолированные PostgreSQL БД.
- Ruff formatter/linter, Bandit, JUnit и отчёты покрытия.
- Baseline ЛР2 с проверкой структуры, затем три изменения схемы.
- Проверки чистой/заполненной схемы и сохранения данных.
- Custom backup/restore, проверка данных и identity после повреждения.
- Два контролируемых мутанта и полный make verify.
- Установщики, инструкция ВМ и сценарий защиты.

В среде подготовки: PostgreSQL 16.11, 137 тестов, покрытие 99,09%,
make verify и сохранённый check.py успешны.
Подробности и ограничения — docs/LR3_VALIDATION.md.
